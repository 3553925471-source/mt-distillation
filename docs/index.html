模型假设与计数规则

适用于恒定相对挥发度、恒摩尔流、全凝器、泡点回流、平衡部分再沸器和单股进料的二元精馏。按操作线交点切换塔段，自动确定本模型约定的最佳进料板。不是多组分、非理想或共沸体系的严格模拟。

  • 相平衡式：y = αx / [1 + (α − 1)x]。逐板计算交替使用相平衡逆式与对应塔段操作线。
  • 全凝器不计级；塔内理论板数扣除一个再沸器等效级。实际塔板数还需要板效率资料。
  • 最后完整阶梯可能越过 xW。小数板数使用该水平步的组成线性插值，是图解估算。
  • 要求 R > Rmin，且满足进料夹点控制的双塔段可行性条件。接近夹点时最多计算 10,000 级。
  • 例题 7-15：D/F = 0.34，先由衡算求 xW；R/Rmin = 1.4，对应实际 R ≈ 2.91221。F = 100 kmol/h 是流量基准。
  • 网页不调用本机 Origin。曲线 CSV 可导入 Origin；自动生成可编辑 OPJU 请使用 Python 本地版。
  • 所有计算在当前浏览器内完成，没有工况上传接口。离线文件不依赖外部字体、脚本或图形库。
